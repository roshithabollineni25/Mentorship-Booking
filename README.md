# MentorSphere AI

## Professional Mentorship Booking Platform

MentorSphere AI is a mentorship marketplace platform that connects mentors and mentees through a centralized system. Users can register, create mentor profiles, schedule mentorship sessions, manage availability, provide reviews, and analyze platform performance.

---

## Features

### Authentication

* User Registration
* User Login
* JWT Token Generation
* Role-Based Access (Admin, Mentor, Mentee)

### Mentor Management

* Create Mentor Profile
* Update Mentor Profile
* View Mentors
* Delete Mentor Profile

### Booking Management

* Create Session Booking
* Approve Booking
* Reject Booking
* View Bookings

### Availability Management

* Create Availability Slots
* View Available Slots

### Reviews & Ratings

* Add Reviews
* Mentor Ratings
* Feedback Management

### Analytics Dashboard

* Total Users
* Total Mentors
* Total Bookings
* Total Reviews
* Most Booked Mentor
* Best Rated Mentor
* Booking Statistics
